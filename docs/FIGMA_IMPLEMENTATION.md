원본 HTML/CSS/JavaScript 구조와 Python API를 유지했습니다. Figma의 정적 예시 수치·프로젝트를 실제 실행 데이터로 취급하지 않습니다.
대시보드 KPI·실행·문제 목록은 기존 `/api/state` 기본 진단 기준이며 페르소나 실행은 사전 테스트와 리포트에서 확인합니다.
50개 타일 데모는 `/#monitor`로 이동했습니다. 실제 페르소나 실행과 별도입니다.
프로젝트 등록과 계정 설정은 기존 localStorage 동작을 유지합니다.

## API 연결 전 남은 디자인 범위

Figma 전체 화면의 제품 구현이 완료된 상태는 아닙니다. 다음은 서버 기능을 먼저 구현해야 합니다.

- 이메일/Google 로그인, 실제 워크스페이스·프로젝트 저장 및 권한.
- 임의 URL 탐색, 로그인 lease, 퍼널 단계 편집·세그먼트 수 조절·시드 반복·좌절 모델 ON/OFF.
- 실측 수집·이벤트 매핑·예측 비교·원인 재현·보정 적용/이력.
- 리포트 공유 링크와 만료·권한, 제품 API를 통한 재테스트 비교.

현재는 고정 3프로필, 최대 동시 3세션, 선택 과업당 3세션을 실행합니다.
UI에서 실행 가능한 설정과 API의 실제 동작을 일치시키고, 없는 실측값·보정값을 표시하지 않습니다.

API 명세는 [API_SPEC.md](API_SPEC.md)에 있습니다. 동일 문서의 기준본은 [BE docs/API_SPEC.md](https://github.com/Exitplain/BE/blob/main/docs/API_SPEC.md)입니다.
