# 로그인 화면

Figma L01~L05, L10의 카드 화면입니다. 입력 없이 `계속` → `로그인` → 기존 대시보드로 이동합니다. Google 버튼도 임시 이동이며 외부 인증을 요청하지 않습니다.

- `components/`: 카드, 이메일 폼, 코드 폼·입력, 로그인 전용 버튼, 세션 만료 안내
- `hooks/useLoginPrototype.ts`: API 연결 시 인증 mutation으로 교체할 화면 전환 이벤트
- `login.css`: 로그인 전용 Tailwind 토큰. 공유 레이아웃·공통 컴포넌트 변경 없음
- `src/assets/login/`: Figma 원본 배경·Google 아이콘

## 확인 주소

| 주소                            | 화면                                                          |
| ------------------------------- | ------------------------------------------------------------- |
| `/login`                        | 이메일 입력                                                   |
| `/login?view=code`              | 인증 코드 입력                                                |
| `/login?view=code-error`        | 인증 코드 오류                                                |
| `/login?view=network-error`     | 네트워크 오류 (예시 이메일 포함)                              |
| `/login?simulate=network-error` | 계속 또는 Google 버튼 클릭 시 한 번 오류 표시, 재시도 시 진행 |
| `/login?view=loading`           | 로그인 중 → 650ms 후 대시보드                                 |
| `/login?view=expired`           | 세션 만료 안내 → 다시 로그인                                  |

이메일·코드는 React 메모리에만 두며 새로고침하면 초기화합니다. 입력 검증, 실제 메일·코드 재전송, 계정 생성, 인증 상태·토큰 저장은 하지 않습니다. 입력이 없으면 설명에 예시 이메일을 표시합니다.

## 사이드바 로그인·로그아웃

- 로그인 전: 사이드바 하단 안내와 로그인 버튼 → 현재 페이지 위에 로그인 모달 표시
- 로그인 후: 메이커 계정 행 → 설정·시작 가이드·관리자(연결 전 비활성)·로그아웃 메뉴
- 모달에서 로그인하면 원래 URL·쿼리·본문 입력을 유지합니다. 단독 로그인 페이지에서는 대시보드로 이동합니다.
- 데모 계정 표시는 `useDemoSessionStore`가 탭의 sessionStorage에 저장합니다. 토큰·비밀번호·인증 권한은 저장하지 않습니다. 로그아웃은 데모 계정 표시만 초기화하며 다른 담당 화면의 상태는 유지합니다.
- `/?auth=expired`로 접속하면 현재 페이지 위에 세션 만료 안내를 확인할 수 있습니다. 실제 세션 만료 타이머·API는 연결하지 않았습니다.
- 대시보드 본문, 기존 프로젝트 메뉴, 사전 테스트와 리포트는 변경하지 않았습니다. 둘러보기 전용 프로젝트 목록은 후속 워크스페이스 작업 범위입니다.

세션 만료 시 입력 복원 기능은 별도로 만들지 않았으므로 안내 문구는 실제 동작 범위에 맞췄습니다.
